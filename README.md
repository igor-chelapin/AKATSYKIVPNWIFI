# AKATSYKI VPN WIFI

MVP-приложение для Windows 10/11, которое позволяет раздавать Wi‑Fi и направлять трафик через один из двух режимов:

- Zapret — обход блокировок через публичный проект `zapret-discord-youtube`.
- Xray — подключение через VLESS/HTTPS-подписку и выбор сервера по пингу.

## Возможности

- Создание Wi‑Fi hotspot через встроенный Windows `netsh`
- Выбор DNS: Xbox DNS, Google DNS или свой DNS
- Поддержка режима Zapret и режима Xray
- Загрузка VLESS/ссылки на подписку и сортировка серверов по задержке
- Логи в папке `logs/`
- Возможность автозапуска при старте Windows

## Требования

- Windows 10 или 11
- 64-битная система
- Права администратора
- Wi‑Fi адаптер (встроенный или внешний USB)
- Python 3.10+ (если запускаете исходники)

## Запуск из исходников

```bash
git clone https://github.com/igor-chelapin/AKATSYKIVPNWIFI.git
cd AKATSYKIVPNWIFI
pip install -r requirements.txt
python app.py
```

Важно: запускать от имени администратора.

## Как использовать

### Режим Zapret

1. Выберите режим `Zapret`.
2. Введите SSID и пароль для Wi‑Fi сети.
3. Выберите DNS.
4. Нажмите `Start`.
5. Подключитесь к Wi‑Fi со смартфона.
6. Доступ к YouTube/Discord и другим сервисам должен проходить через ПК.

### Режим Xray

1. Выберите режим `Xray Key`.
2. Вставьте VLESS URL или HTTPS подписку.
3. Нажмите `Load Servers`.
4. Выберите сервер с минимальным пингом.
5. Нажмите `Start`.
6. Приложение запустит Xray и раздаст Wi‑Fi через него.

## Папка logs


## Сборка в EXE

```bash
pip install pyinstaller
python build.py
```

Готовый exe будет в папке `dist/`.
